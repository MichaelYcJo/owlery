- **The files to split.** `apps/desktop/test/chain.test.ts` holds 179 cases in 3,662 lines: thirteen groups of calls up to line 907, then four groups that each run chains, at lines 908, 2303, 2836 and 3315. `apps/desktop/test/daemon.test.ts` holds 440 cases in 9,344 lines under the thirty top-level groups from line 292. - **The check's git.** `pr-check/skills/code-review/scripts/chain_check.py:370-379` is the one function most of the check's git calls go through.
- **The gate and `check`.** `agentory/config.json:5` holds the gate as one string. `.github/workflows/check.yml:22-47` is one job on `macos-latest`. `apps/desktop/test/rerun-unstarted.test.ts` holds the cases of `.github/scripts/rerun-unstarted.mjs`, which is the precedent for a case under `apps/desktop/test/` that runs a script of the repository's top level.

**What breaks in six months.** A case opens a document of the repository that `scripts/suite-reads.mjs` does not name, and a documents-only pull request that changes it skips the suite and merges a break. The next code change's suite finds it, one pull request late. `docs/testing.md` *A document the suite reads* is what holds it until then, and review reads it. A second way: a world's copy rests on a copied path being written wherever a file holds the old one, so a world that stores its path in a form the copy does not rewrite, such as a compressed file, fails every case that takes it. That failure is loud and at the first case.

- **Every test file opens with a layer line.** A branch cut before this merges that adds a test file gets a stop at the suite's start, with the file's name, until the file names its layer.
