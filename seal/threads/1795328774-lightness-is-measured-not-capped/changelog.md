# Changelog: the 500 MB of one scene is a measurement, not a limit

Issue #121. The design documents stated the about 500 MB that the app itself read with four terminals visible as a target the app had to stay under, and fixed the panes a work item's view shows at once at four on every machine, because four is the count that scene was measured at. Read as a limit, that number stopped every feature from here on: an in-app preview (#120) was first weighed against it.

- **Owlery spends as little memory as it can, and a feature costs nothing while nobody uses it.** What a scene costs is measured and published, beside the same scene in comparable products, and no number of a reference scene is a limit on a feature. The four-terminal scene keeps its measured numbers, 491.1 to 503.4 MB on 2026-11-19 (`apps/desktop/measurements/memory.md`), as a measurement. No comparable product has been measured in that scene yet. `docs/architecture.md` *Memory design* holds the rule, and `docs/product.md` *Foundation* and *Where performance differs* state it.
- **A feature is built first, and made efficient where a measurement shows its cost.** A feature is built with ordinary care, so that it holds nothing while unused, and its cost is then measured. Efficiency work follows a measurement, as #9 removed the terminal screen each hidden pane kept in the window. A tight number set before a feature is built is not a design input, and the reference scenes are measured again as features land, with `pnpm run measure:memory`.
- **The limits Owlery keeps are defaults read from your machine, which you see and change.** They are how many agents and worktrees run at once, and how many panes a work item's view shows at once. Issue #32 builds them. Until then a view still shows at most four panes, and nothing caps the agents and the worktrees.
- **The roadmap measures lightness the same way.** v0.1's done criterion is that the reference scenes are measured and published beside comparable products, and its open decision asks which scenes to measure beside the four-terminal one. The rows of milestones 1 and 5 say the same.
