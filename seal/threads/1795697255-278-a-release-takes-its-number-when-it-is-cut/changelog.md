# Changelog: a release takes its number when it is cut

Issue #278. The roadmap gave each release its number when its milestone opened, held 0.1.0 for the release that closes milestone 5, and named the later goals v0.2 and v0.3. Each change of scope moved the numbers: on 2026-11-26 the owner cut 0.1.0 as the minimum to publish, and the numbers 0.0.6 to 0.0.8 that milestones 3, 4 and hardening held were left on no release.

- **A release takes its number when it is cut.** A GitHub milestone is named by its goal, so an issue keeps its milestone whichever release ships it. The roadmap's release table holds the numbered releases, 0.0.1 to 0.0.5 and 0.1.0, and a second table holds the goal milestones: after launch, milestones 3, 4 and 5, hardening, and the owner's work by hand.
- **How the number is chosen.** Owlery stays on 0.x, and only the owner moves it to 1.0.0. A public release's number moves its minor part where a person would feel a new workflow or capability, and its patch part where it holds fixes and polish. The orchestrator proposes the number with its grounds and the owner approves it. 0.1.0 is the first public release, and no 0.0.x release follows it.
- **Until releases are cut from `main`, the number is set when the release branch is cut.** A connected repository's check clones the branch `release/v<version>` of its pinned version until the tag exists, so the number stays after the cut. Merging into `main` (#279) and a beta channel (#280) are named as later work.
- **Release 0.0.5 and release 0.1.0 say what they are.** Release 0.0.5 is the walk release, with the `.dmg` (#78) among what it carries. From it on, every release's tag gets a `.dmg` on its GitHub release, signed ad hoc until the Developer ID certificate's secrets are in the repository. Release 0.1.0 is the first public release, published on Sunday 2026-11-29.
- **The goal once called v0.1 is called "the first version"** in the roadmap, the architecture, the product document and both READMEs. What comes after it carries no version number: the phone app comes next, and other companies' agents for the roles after it.
