# Changelog: Owlery runs IADD, and the Owl Chain is its default workflow

Issue #322. Owlery's chain still spoke the AgenticSeal plugin's language: the seal, the sealer, `seal/`, `guarantee.md`, the check `seal`. That vocabulary named the artifact and not the method, and the app leaned on the plugin in code: it read the person's Claude Code settings to find it and asked before a pane which chain to carry. On 2026-11-28 the owner set the method the chain follows, IADD (Independent AI-Driven Development, *Zero Self-Approval*: no AI approves its own work), and the names that come from it.

- **IADD is defined in the documents, and the product speaks its names.** `docs/iadd.md` and its Korean edition state the concept, the five principles, the names and the names set aside, the records folder and the check, what a workflow is, and what holds for every workflow. The README, the product, architecture, roadmap, name and design documents state Owlery as one tool that runs IADD, with the Owl Chain as its default workflow. The last role is the inspector, its record is the inspection, and an inspection is cleared, lapsed or not cleared.
- **The records and the check take IADD's forms.** A connected repository's records stand under `iadd/`, and the inspector's verdict stands in `inspection.md`. The pull request check is named `inspection`, its workflow is `.github/workflows/owlery-inspection.yml`, and its titles read "Cleared by the Owl Chain at", "Inspection of the Owl Chain lapsed" and "Not cleared: no inspection at the head commit". A verdict block now names the workflow and the inspector module that produced it.
- **A connected repository moves in one commit the person reads first.** A repository whose records stand in the earlier form reads as such on its row, and no chain runs there until it moves. The dialog "Records and check" shows the commit that moves the records to `iadd/` in IADD's forms and replaces `owlery-seal.yml` with `owlery-inspection.yml`, and writes nothing until the person confirms. An inspection cleared before the move lapses at the move's commit. A work item's branch that held records before the move moves its own with the chain command's `migrate`. A repository whose rules required the check `seal` requires `inspection` in its place, which an administrator sets on GitHub.
- **The chain choice is gone.** A Claude Code pane of a repository on the Owl Chain carries the role bundle whatever plugins the person enables, and the window asks nothing before it opens. Owlery no longer reads the person's Claude Code settings or plugins, writes no settings file of a pane's own, and no longer tells AgenticSeal's `hygiene.yml` apart. A repositories file an earlier build wrote with the choice is still read.
- **The Owl Chain is a workflow file.** The role bundle ships `workflows/owl-chain.json` and `inspectors/owl-chain.json`, and both the daemon's role sessions and a pane's chain read each stage's agent, documents and model from them. The inspector still runs on `opus`, now passed with `--model`, and the daemon does not start where the bundle's files are refused. What the chain does is unchanged.
- **The window uses the new words.** "Cleared at" and the commit where it said "Sealed at", "Inspection lapsed" where it said "Seal broken", "No inspection yet", the role "Inspector", and the tab "Inspection sheet" where it said "Back of the seal". The summary counts, as in "2 cleared, 1 inspection lapsed". The owl on red wax stays as the inspection's mark.
- **The settle command removes nothing.** `pnpm --filter @owlery/desktop run settle` reads the records under `iadd/threads/` and prints the directories a settle keeps, each with the rows that keep it, and, with `--list`, the decisions made without asking. It no longer takes `--apply` and runs no other tool.
- **This repository stays in the AgenticSeal plugin's forms.** Its records stay under `seal/`, and `owlery-seal.yml` keeps its pin at 0.1.0, until the plugin takes IADD's names and the move and the raised pin go in one commit (#322 *When it lands*, step 4). The app's offer to move this repository's records is not taken here before then.
