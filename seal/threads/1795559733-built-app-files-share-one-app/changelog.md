# Changelog: the cost of launching the built app for each test file is measured, and the built-app files run as one batch

Issue #149. Each test file that starts the built app launches an app of its own, and the issue asked for one app left open that every such file shares, on the ground that a launch for each file is slow. Nobody had measured what a launch costs against what a reset of an open app would cost.

- **`pnpm run measure:launch` measures it.** Run in `apps/desktop`, it builds and launches the app ten times as each built-app file does, and resets one app left open ten times. It prints each part of a launch and of a reset with its median, lowest and highest, the saving one open app would bring for each launch, and the app's memory. `OWLERY_LAUNCH_RUNS` sets another count. The run fails and prints no table where a reset left the old daemon running, left the new daemon without the environment the reset set, or left a file in the daemon's run folder.
- **One open app would save about half a second for each launch, so the files keep launching an app each.** On the owner's Mac a launch without its build took 688 ms at the median of ten, and a reset of an open app 181 ms, a saving of 507 ms for each launch and about 8.6 s for a run of the suite. The open app also held 57.6 MB more after ten resets than before the first. `apps/desktop/measurements/built-app-launch.md` publishes the numbers, their commands and the machine's load during each run. Whether one open app is built all the same is the owner's word, and this release does not build it.
- **`pnpm run test:app` runs the built-app files alone.** Run in `apps/desktop`, it runs every test file that starts the built app, one at a time, and no other test file. `pnpm run check` still runs every file.
- **For an agent working in this repository:** an agent runs one built-app file alone while it works on a case of that file, and all of them with `OWLERY_BACKGROUND=1 pnpm run test:app` when a phase or a fix pass ends. The settle writes the rule into `docs/architecture.md` *Measure before building*.
