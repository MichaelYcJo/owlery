## Scope

In:

1. **A measurement of a launch against a reset of one open app, as a command the tree holds.** `apps/desktop/test/launch.ts`, new, holds the measurement's functions, and `apps/desktop/test/launch.test.ts`, new, runs them where `OWLERY_MEASURE_LAUNCH` is `1`. 2. **A reset that fails where it did not reset.** After each reset the measurement reads that the daemon is a new process, that the daemon's environment holds the value the reset set, and that the run folder holds nothing left before the reset. ## Data & interfaces

No schema, no message of the protocol and no file under `apps/desktop/src` changes.

**`test/launch.ts`.** It imports `BuiltApp`, `buildApp`, `alive` and `untilGone` from `./built-app` and changes none of them. Every start passes `SHELL: "/usr/bin/true"`, as `test/keep-awake.test.ts:117` does, so no shell of the person's and no `claude` starts, and `OWLERY_WORKTREES` set to a temporary folder the run removes. No pane is opened, so the measurement takes no pseudo-terminal. "Ready" is the page's status line reading `Daemon running, no agent`, which `test/keep-awake.test.ts:126` waits on. The measurement reads the line every 10 ms and not with `BuiltApp.until`, which reads every 100 ms and would add up to that much to a part of about 100 ms.

- **A launch** is timed in four parts: `buildApp()`; `BuiltApp.start` until it returns; from there until ready; and `stop()`. One build that is not timed runs before the first timed launch, as each built-app file of the suite builds after the file before it has built.
- **A reset** is made on one app started with `inspectMain`, and is timed in six parts, taken in this order. The order is the one the framer's probe ran (*Grounding*), and part 1 is what keeps the page from starting a daemon while the folder is emptied.
  1. The window loads `about:blank`, asked in the main process through `evaluateMain`.
  2. The daemon `daemonPid()` names is sent SIGTERM and waited on until it is gone.
  3. Every entry of the run folder is removed, and `appearance.json` of the user data folder.
  4. The next environment is set on the main process's `process.env`, through `evaluateMain`. The measurement sets one variable of its own, `OWLERY_LAUNCH_MARK`, to a value that names the reset, `reset-<n>`. The open app starts with `OWLERY_LAUNCH_MARK=start`.
  5. The window loads the URL it showed before part 1, which is `dist/index.html`, asked in the main process.
  6. The page is ready.
- **What a reset is judged by**, after part 6: `daemonPid()` differs from the id before the reset; the new daemon's environment, read with `ps eww -o command= -p <pid>`, holds the value part 4 set; and a file the measurement wrote into the run folder before the reset is gone. One function takes the three readings and answers what failed, so its cases run without the app.
- **The memory samples** are the sum of `phys_footprint` over the app itself, as `test/memory.ts#splitProcesses` and its readers define it. Three are taken, each 5 seconds after ready: in the first launched app, in the open app before its first reset, and in the open app after its last reset. `test/memory.ts` exports the readers the measurement needs where it does not export them now, and nothing else of it changes.
- **The runs.** `OWLERY_LAUNCH_RUNS` names how many launches and how many resets one run of the command makes, 10 of each where it is absent. A value that is no whole number above 0 fails the run with a sentence that names the variable, as `test/memory.ts#planOf` does for its variables.
- **What the command prints**, to the run's own output as `test/memory.test.ts:302-305` does: the heading `test/memory.ts#heading` gives, with the commit from `treeNow`; one table of the launch's four parts and their sum, with the median, the lowest and the highest of the runs; one table of the reset's six parts and their sum, the same way; one line with the median saving for each launch, which is the launch's sum without the build, less the reset's sum; and the three memory samples in MB as `memory.md` counts one.
- **A run a signal ends** stops its app and daemon before it exits, with `stopNow`, as `test/memory.ts#measure` does.
