# Changelog: a pane's past output is searched, kept longer, and its paths open in the editor

Issue #231. A pane's terminal kept 1,000 lines of history, and the daemon kept the last 256K characters a pane printed, so a pane that left the screen came back with even less. Nothing searched what a pane had printed. A path a pane printed was a link that showed the file in Finder, and the line number after it was dropped. A paste into a pane gave its program text alone, so a screenshot on the clipboard reached no agent's CLI.

- **A pane keeps 5,000 lines of history by default.** The Machine dialog holds a row "Scrollback lines", after "Panes side by side", where a person sets a whole number from 1,000 to 50,000 or returns to the default. The daemon keeps 256 characters of each pane's output for each of those lines, so a pane that comes back onto the stage holds the history again. A change reaches every pane that lives at once, and a smaller number drops the older output. A daemon of an earlier build sends no scrollback, and its window keeps 1,000 lines and draws no such row.
- **⌘F opens a find bar over the pane in front**, and the pane's menu holds "Find…". The bar searches what the pane's terminal holds, from the newest line to the oldest, with "Match case" and "Regular expression". Its count reads "3 of 17", "No match", "More than 1,000 matches" or "Not a regular expression". Enter and ⌘G go to the next older match, and Shift+Enter and ⇧⌘G back toward the newest. Escape in the bar's field closes it, and in the terminal it stays the program's. Every match is outlined in the terminal's ink, and the match in front is the terminal's selection.
- **A ⌘ click on a file a pane printed opens it in the editor the person chose, at the line and the column the pane printed after its path**, as `src/a.ts:12` or `src/a.ts:12:5`. ⇧ ⌘ click shows the file in Finder. The link's card reads "Open in" and the editor's name, "Show in Finder" and "Copy path". A folder's link is as it was.
- **The editor is chosen once, in a new Settings dialog.** "Settings…" in the application menu opens it, on ⌘,. Its field "Open files in" offers the editors of Owlery's list that the Mac holds, Visual Studio Code, Cursor, Zed, Sublime Text and Xcode, and "Show in Finder". Until a person has chosen, the first ⌘ click on a file opens the dialog, and a Save that names an editor opens the file. Where the person chose "Show in Finder", where the Mac holds no editor of the list, or where the chosen editor is gone, a ⌘ click on a file shows it in Finder as before. Owlery opens a file in no app but these editors.
- **A paste into a pane hands its program a file's path where the clipboard holds a file or an image.** Files copied in Finder are pasted as their paths, written as the paths of dropped files are. A paste that holds text pastes the text, as before. An image with no text, such as a screenshot copied to the clipboard, is written as a PNG file into the folder `owlery-pasted` of the system's temporary folder, readable by the person alone, and the pane is handed that file's path, so the CLI of any agent reads the image as a file. "Paste" in the pane's menu does the same where the clipboard holds no text. Each such write removes that folder's files older than seven days. Control+V stays the key of the pane's program: Claude Code reads the clipboard itself at that key.
- **What no run has shown yet.** Whether Finder's copied files and a screenshot reach the window's paste as files, and not as text, was not read on this Mac, nor whether Control+V in Claude Code attaches an image from the clipboard. The commands Cursor, Zed and Sublime Text take a line with were not read on a Mac that holds them: where one stands elsewhere in its bundle, Owlery opens the file in that editor at no line. The owner's walk of 0.0.5 answers them.
- **For a contributor:** `pnpm run screenshots` now also captures the find bar over a pane, as `<theme>-<appearance>-find.png`, and the Settings dialog, as `<theme>-<appearance>-app-settings.png`. `apps/desktop/measurements/memory.md` holds the scene of four terminals measured at the new default.
