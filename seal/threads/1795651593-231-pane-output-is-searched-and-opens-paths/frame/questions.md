# Questions for the planner: a pane's past output is searched, kept longer, and its paths open in the editor (#231)

`routing.md` answers `Automation` `yes`. No row below holds the build. Each row's default is what the build makes, and the owner may overturn it after the release.

The issue left these judgments open, and the tree or a probe answered them:

- Whether Claude Code's own Control+V works in a pane, and what a paste of an image builds: `frame/design.md` *Grounding*, "The check the issue asks for, Claude Code's own paste in a pane", and `frame/plan.md` *Alternatives considered*, the row "At ⌘V with an image, send Control+V to a Claude Code pane". The one part no probe ran is Q3.
- The scrollback's default, its bounds and what it costs for each pane: `frame/design.md` *Data & interfaces*, "What the scrollback costs for each pane", and `frame/plan.md` *Alternatives considered*, the rows on the buffer of characters and on a default above Orca's.
- Where the scrollback is set and who keeps it: `frame/plan.md` *Alternatives considered*, the rows "Keep the scrollback as the window's own choice" and "Put the scrollback in the Settings dialog".
- Where the editor is chosen and who keeps the choice: `frame/plan.md` *Alternatives considered*, the rows "Keep the editor's choice in the daemon", "A control for the editor in the sidebar's foot" and "Take the first installed editor of the list with no question".
- How a path's line reaches the editor: `frame/design.md` *Data & interfaces*, "How each editor takes a file and its line", and `frame/plan.md` *Alternatives considered*, the row "Open a file with `open -a <editor> <file>` alone".
- Whether a file may open in the app the system gives it: `frame/design.md` *Grounding*, the row for *Screen framework: Electron*, "a file is shown selected in its folder and is never opened in an app".
- The find bar's keys and the way "Next match" steps: `frame/design.md` *Scope* items 8 and 9, and `frame/plan.md` *Alternatives considered*, the row "\"Next match\" steps down the output".
- Whether the find bar's matches need tokens of their own: `frame/plan.md` *Alternatives considered*, the row "New tokens for a match and for the match in front".
